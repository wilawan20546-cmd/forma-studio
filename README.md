# Forma Studio v2.0

เว็บสำหรับสร้างมู้ดบอร์ดและ Prompt แปลงภาพเป็นเวกเตอร์ ส่งออกเทมเพลต และแชร์บรีฟงานพิมพ์ ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีขั้นตอน build, API key, CDN, backend หรือฐานข้อมูล ลิงก์ค้นและสร้างภาพจะเปิดเว็บภายนอกเมื่อกดเท่านั้น บริการสร้างภาพอาจจำกัดโควตาหรือต้องลงชื่อเข้าใช้

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| index.html | ฟอร์มบรีฟ มู้ดบอร์ด Prompt ตัวแปลงภาพ และหน้าตั้งค่า SVG |
| style.css | หน้าตาและเลย์เอาต์สำหรับเดสก์ท็อปและมือถือ |
| js/concepts.js | ตารางกฎประเภทงานและอารมณ์ภาพ สี และลวดลาย SVG |
| js/exporter.js | ตารางปฏิทิน การแปลงหน่วย และโครงสร้าง SVG |
| js/vectorizer.js | อ่านพิกเซลผ่าน Canvas ลดจำนวนสี สร้างเส้นขอบ และจัดรูป SVG |
| js/vector-ui.js | อัปโหลด พรีวิว คัดลอกรหัสสี และส่งงานเข้าเทมเพลต |
| js/sharing.js | สร้าง Prompt และเข้ารหัส/ตรวจข้อมูลลิงก์แชร์ |
| js/app.js | เชื่อมฟอร์ม ผลลัพธ์ พรีวิว ดาวน์โหลด และคืนค่าจากลิงก์ |
| .nojekyll | ให้ GitHub Pages เสิร์ฟไฟล์สแตติกโดยตรง |

## เปิดใช้

แตก ZIP แล้วเปิด index.html ในเบราว์เซอร์ได้ทันที จากนั้นกรอกบรีฟ กดสร้างแนวทาง และเลือกการ์ดเพื่อส่งชุดสีและลวดลายไปยังเทมเพลต

สำหรับ GitHub Pages ให้นำไฟล์ทั้งหมดรวมถึง .nojekyll ไปไว้ที่รากของรีโพซิทอรี เลือก Settings → Pages → Deploy from a branch แล้วเลือก main และ /(root) ตาม [เอกสาร GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) ใช้รีโพซิทอรีสาธารณะได้บน GitHub Free

## เวิร์กโฟลว์ภาพ

1. เลือกคอนเซ็ปต์แล้วคัดลอก Prompt ภาษาอังกฤษจากส่วน Prompt สำหรับสร้างภาพ
2. เมื่อนำภาพ PNG หรือ JPG กลับมา ให้ปรับจำนวนสี (สูงสุด 2–16 ตามที่เลือก) และระดับลดจุด Path (0–5) พาเลตอาจมีสีน้อยกว่าค่าสูงสุดหากต้นฉบับมีสีน้อย
3. ตัวแปลงย่อด้านยาวสุดเป็น 384 px หากภาพใหญ่กว่า ใช้การแบ่งกลุ่มสีและลากเส้นรอบพื้นที่สี ตัวเลือกลบพื้นหลังตัดสีเกือบขาวที่เชื่อมถึงขอบภาพ พื้นที่ขาวที่ถูกสีอื่นล้อมไว้จะคงอยู่
4. กดรหัส HEX เพื่อคัดลอก ใช้ชุดสีในเทมเพลต หรือวางภาพเวกเตอร์ที่ปรับขนาดตามกรอบโดยรักษาสัดส่วนใน Layer_Artwork สองตัวเลือกนี้ทำงานแยกกัน กดกลับไปใช้คอนเซ็ปต์เพื่อล้างทั้งคู่

## แชร์บรีฟ

เมื่อเปิดเว็บจาก GitHub Pages ให้กด **คัดลอกลิงก์แชร์บรีฟ** ลิงก์เก็บบรีฟที่ใช้สร้างผลลัพธ์ ข้อความฉบับร่าง คอนเซ็ปต์ที่เลือก การตั้งค่าตัวแปลง การตั้งค่าเทมเพลต และชุดสีที่ใช้ใน URL hash แบบ Base64URL ทุกคนที่ได้ลิงก์อ่านข้อมูลนี้ได้

หากวางภาพเวกเตอร์ในเทมเพลต ภาพขนาดเล็กจะติดไปกับลิงก์ด้วย (ข้อมูลภาพไม่เกิน 4,500 อักขระก่อนเข้ารหัส) สำหรับงานที่ใหญ่กว่านั้น เว็บจะแจ้งให้ส่ง SVG แยก ลิงก์จะไม่ส่งต้นฉบับ PNG/JPG และยังคืนค่าบรีฟกับการตั้งค่าได้

## ส่งต่อสู่งานพิมพ์

- เทมเพลตปฏิทินรวม 12 เดือนในอาร์ตบอร์ดเดียว ใช้ปฏิทิน Gregorian และเลือกให้แสดงปี พ.ศ. หรือ ค.ศ. ได้
- ขนาดที่กรอกคือขนาดตัดจริง ขนาด SVG รวมระยะตัดตกด้านละ 3 mm เช่น 210 × 148 mm จะได้ SVG ขนาด 216 × 154 mm
- SVG แยกกลุ่ม Layer_Background, Layer_Artwork, Layer_Calendar_Grid และ Layer_Bleed_Guides โดยกลุ่มปฏิทินมี Month_01 ถึง Month_12
- เปิด SVG ด้วย Illustrator แล้วดูโครงสร้างกลุ่มและปรับเส้นไกด์ในแผง Layers กลุ่ม SVG และเส้นไกด์เป็นวัตถุเวกเตอร์ ส่วนค่า bleed ของเอกสาร AI ให้ตั้งแยกเมื่อจำเป็น ควรตรวจฟอนต์ไทยและขนาดหลังเปิดไฟล์
- สีใน SVG เป็น RGB ตัวเลข CMYK ในมู้ดบอร์ดเป็นค่าประมาณจาก HEX สำหรับประเมินเบื้องต้น
- เทมเพลตซองและบรรจุภัณฑ์เป็นโครงจัดวางหน้า ใช้ไดคัทจากผู้ผลิตสำหรับการผลิตจริง
